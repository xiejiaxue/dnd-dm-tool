# 酒馆内的深水城日期

独立战役日历已合并到 `/tavern`，旧 `/calendar` 链接自动转到酒馆并保留桌团参数。

酒馆页顶部「今日深水城」显示当前游戏日期及当天公共活动。默认第1个营业日为1492 DR彻斯20日，第2天双游行，第3天不会向玩家透露火球案。进入下一营业日自动推进日期，打烊结算不重复推进。月外节日、盾会及跨年均正确计数，1492年的一次性活动不会在后续年份循环。

「桌团与日期提示」允许关联已加入桌团。服务器基于当前会话成员身份返回活动数据：主持人／协助主持人可看到折叠的特殊日期提示，并调整第1个营业日；玩家和访客只收到公共活动，无主持人切换入口。秘密预置日程只在 Worker 中，不打包到前端。剧情是否发生由主持人裁定。

日期使用酒馆的本机进度，`calendarStartDay` 随酒馆备份保存；旧酒馆存档无此字段时默认彻斯20日。关联桌团仅用于校验身份，不改变现有酒馆的本机存档模式，不向玩家同步私人剧情进度。

旧独立日历的 localStorage 数据仍保留，但不自动覆盖酒馆账本或营业日；本次整合采用预置时间线和酒馆日期，不导入旧日历自定义事件。

事件文案采用原创角色引语／笔记和可展开的「城中掌故」。瓦罗引语是依据本地模组设定改写的跑团素材，非出版物原文。背景参考双游行附录、嘉年华与庄园章节，以及原版深水城节庆说明。公开莱拉受难日与主持人猩红盛宴为独立事件，权限分别处理。

「下一日」用于筹备和晨间准备阶段的休业日。只增加 `calendarSkippedDays`，不增加营业天数、不扣钱、不结算工资或生成账单；日期 = 起始日期 + 营业天数 − 1 + 休业天数。营业中和待结算阶段禁用，完成当日正常流程后可继续休业。休业天数随酒馆备份保存，旧存档默认为0。

日期区支持「前一日」和「选择日期（1492 DR）→设为今天」，可直接回到更早日期。改期通过独立的 `calendarAdjustment` 保存，不撤销营业、资金、事件记录或账本；之后继续「下一日」会从调整后的日期推进。最早可设为1492年严冬之月1日。

营业日志与账单显示费伦日期及营业序号。`TradingDay.calendarDay` 在开门时记录绝对日序，结算时原样写入 `Settlement.calendarDay`，用于每日结算、往日日志和经营账本；之后手动改期不改变旧记录。旧版历史账单缺少日期时标记「费伦日期未记录（旧存档）」，不按当前偏移猜测。导出／导入保留日期。
