# 龙后的宝山

首页「新战役 → 模组 → 龙后的宝山 → 创建并进入」。13 个场景对应原书全部地图：00 剑湾总览、01 至绿镇、02 劫掠者营地、03 育龙场、04 卡纳特客栈、05–08 涅瑞塔堡（外围与一层、二层、三层、地下层）、09–10 狩猎旅舍（外围与一层、上层与地下室）、11 帕纳斯特村庄、12 通天堡。第 4 章商路没有专用地图，商队事件、受雇规则与规划事件放在剑湾总览的遭遇与区域要点里。

## 主持人操作

- 新战役自动在各房间放置 495 个隐藏 Token（固定遭遇与在场人物），用现有框选工具统一显示。按原书状态开局：育龙场三只未驯完的护卫龙兽 33/52 生命值，狩猎旅舍的米瑞塞拉 1/16。白天与夜间人数不同的房间预置白天的状态，夜间换岗、援军与警报增援在条件遭遇里按需加入。
- 战术地图按原书比例校准：一格印刷方格 = 棋盘一格（5 尺 = 100 像素）。涅瑞塔堡一至三层原图 1 格 = 20 尺（四格棋盘），涅瑞塔堡地下层与帕纳斯特 1 格 = 10 尺（两格棋盘）。Token 按体型：微型半格、中小型一格、大型两格、巨型三格。剑湾、至绿镇与劫掠者营地没有网格，人物标记较小。
- 「资料 → 龙后」：
  - 本场景遭遇：固定遭遇、在场人物、条件遭遇（夜间换岗、援军、途中遭遇）与随机遭遇表（至绿镇 d8、深水城以北 d20、亡者沼泽 d12、贸易公路事件 d12），可按数量加入隐藏 Token。
  - 区域要点：每个编号房间的特征、检定 DC、陷阱、发展与宝藏，按原书页码整理；含剧透，仅主持人可见。
  - NPC 与怪物库：144 份中文数据卡——附录 B 全部 15 份专属数据（龙翼按原书由龙爪推导）、本书用到的 66 份 2014 通用模板、具名人物（按原书指定的模板与调整，如利南 8 生命值、四臂巨魔特雷普森）和 21 位第 4 章商队旅伴。也可在「查询」里按名字或别名搜（青怒、狂蛙人、欧瑟斯坦、树绳妖等）。
- 原书没有战斗数据的人物（镇长、厨师、商队旅伴等）只给身份与跑团用途，不编造 HP。

## 来源与维护

素材来自用户本地《龙后的宝山》目录中的中译 PDF（v1.0）及其整理资料。地图用 poppler `pdfimages` 按原字节提取，上传到既有私有 REFERENCE_DATA bucket。数据卡（`shared/hoard/cards.json`）由整理资料的附录 B、2014 通用模板与 NPC 档案转换后人工核对；场景预设（`shared/hoard/scenes.json`：遭遇、锚点、区域要点）为人工整理的数据，锚点按地图上的房间编号目测标定，使用原图归一化坐标。原译文疑点（蒙达斯长戟伤害类型、塔利斯“凛冬打击”等）保留原文。

```sh
python3 scripts/build-hoard.py /path/to/龙后的宝山   # 刷新地图元数据、派生字段、index.json 与 output/hoard
node scripts/publish-hoard.mjs --remote             # 先传 13 张地图，最后提交清单
npm test
npm run build
```

构建脚本可重复运行：它从卡片派生每条遭遇的 key、名称、HP、先攻和 Token 体型，生成 `index.json`，并核对锚点范围与自动放置条件。更换地图会改变内容哈希（asset id），需要重新上传清单并发布 Worker。

## 验证

`worker/test/hoard.test.ts` 覆盖：预设与卡片、地图一致；13 张地图导入、战役素材隔离、全部隐藏 Token 及起始 HP、体型尺寸；场景预设与区域要点仅主持人可读；条件遭遇命令幂等；中文名与别名搜索、数据卡与 Token 图；缺图时拒绝创建。

## 重置版

首页「新战役 → 模组 → 龙后的宝山（重置版）」，资料面板标签为「龙后重置版」。它来自用户本地《龙后的宝山/重构版》：依 The Alexandrian 的节点设计思路编写的本地重构，不是官方出版物，也不是 Justin Alexander 发表的完整重置版；新增信件、时限、派系交易、遭遇编组和结局规则均为本地自编。与原版并存，原版模组不受影响。

- 沿用同样的 13 张地图（独立的 `map-hdqr-*` 资源与 R2 前缀）和原版全部数据卡；另加重置版自编配置（博格·卢克采用老兵模板，`HDQR__bog-luck`）。
- 场景对应重构版的 S1 至绿镇、S2 营地与育龙场、S3 北上（剑湾总览）、A 卡纳特、B 涅瑞塔（四层）、C 旅舍（两层）、F 帕纳斯特与通天堡。场景概况写明目标、可选冲突、时限与出口；剑湾总览集中放线索总表、固定日历（D0–D36）、五项局势、敌方反应与派系交换。
- 新战役只放重构版列出的默认编组，共 173 个隐藏 Token；未列出的原版敌人与陷阱不自动出现。追兵、增援与条件事件在「本场景遭遇」里按需加入。
- 区域要点保留原版每个房间：先写「重置版」用途（未启用的房间注明默认不安排遭遇），再附「原版参考」原文。

`shared/hoard-remix/` 存放重置版数据，`scripts/build-hoard.py` 同时构建两个版本，上传用 `node scripts/publish-hoard.mjs --remix --remote`。`worker/test/hoard-remix.test.ts` 覆盖地图复用、默认编组、主持人专用接口与搜索。
