# 剧情路线与快速定位

## 快速定位（所有人）

棋盘右下角缩放面板下方有「定位」一行：

- **全图**（Shift+L）：整张地图放进视野。
- **队伍**（L，未选中棋子时）：框住所有玩家棋子。
- **选中**（L，选中棋子时）：镜头移到选中的棋子并放大到约 10 格范围。

镜头移动是一段 0.3–0.65 秒的平滑飞行（中心直线移动、缩放按比例变化）；系统开启「减少动态效果」时直接跳到目标。滚轮或拖动会立即打断飞行。DM 用「同时拉取所有人的视角」标记时，玩家的画面也以同样的方式飞过去。

## 底图缩放不再让棋子错位

DM 调「地图图片」缩放时，敌人、玩家棋子、墙和地图笔记的坐标按同一比例移动，留在底图上的原位置；棋子大小不变（模组地图的棋子仍按印刷网格自动调整）。拖动滑块时就能预览，松开后作为一次 `updateMapScale`（`movePieces: true`）提交，可用撤销整体还原。从备份恢复场景时不带此标记，棋子按备份坐标放置。

## 房间描述

在棋盘左下角的房间列表点一个房间，镜头会飞到它在地图上的位置并打开描述卡。卡片下方：

- **定位**：再次把镜头移到房间。
- **带玩家过去**：在房间处标记，并把所有玩家的视角移过来。
- **已探索**：勾选后，列表和地图圆圈显示 ✓，剧情路线同步计数。

## 剧情路线（DM）

资料面板「剧情」页签，仅主持人和协作 DM 可见：

- 顶部：完成进度、当前场景与一句概况、下一场（「前往」或「完成本场 → 下一场」）。
- 按模组章节分组列出本战役的所有场景。圆点点击切换「未开始 → 进行中 → 已完成」；「前往」切换场景并把未开始的场景设为进行中。
- 展开场景：「本场要完成什么 · 开场准备」（场景概况全文）、剧情步骤（重置版 v2 的 a01… 小节）和地点清单。每项可勾选完成，点名称在资料面板读全文，点「定位」会切到该地图并飞到房间、打开描述卡。
- 没有模组预设的场景也会列出，只是没有步骤。

进度保存在战役的 DM 任务追踪里（`campaign.questProgress`，键为 `scene:<场景ID>` 与 `area:<场景ID>:<房间编号>`），和深水城派系任务一样不发给玩家，无需新的数据库结构。场景列表由 `GET /api/campaigns/:slug/story` 提供，仅主持人可访问。

目前只有施特拉德重置版 v2 的房间带地图坐标；其他模组的房间显示「未标」，「定位」不可用，其余功能照常。
