# 施特拉德的诅咒

首页「新战役 → 模组 → 施特拉德的诅咒 → 创建并进入」。36 张原始地图按章节编号排列，含鸦阁城堡各层、村镇、琥珀神殿与附录死亡之屋。场景首次进入自动适配视窗；在画布尺寸就绪后再绘制，确保含隐藏 Token 的存档刷新正常。沿用现有地图缩放、迷雾、场景切换、Token 拖动、显隐、HP、先攻、战役库、邀请与存档功能。

## 主持人操作

- 新战役自动生成 505 个隐藏 Token，按地图区域锚点展开。位置为区域内可调整的开场布置，城堡等轴图仍需主持人裁定距离。
- 「资料 → 施特拉德 → 本场景遭遇」列出该图所有固定遭遇、在场人物、条件事件、增援与随机备选，含数量、区域、条件、来源页码、数据卡与批量放置。
- 随机数量、存活池与跨层交战不自动实例化；实际触发后输入数量加入。新增单位对玩家隐藏，可用现有框选工具统一显示。
- 「NPC 与怪物库」收录 301 份中文卡（包括场景变体），支持姓名及章节筛选、查看完整能力/动作、放置 Token、加入战役库。
- Token 为与深水城相同用途的姓名圆形标记，采用巴洛维亚配色。原文未给战斗数据的人物保留标记，不编造 HP。
- 跨图重复出现的具名人物不代表多个独立个体；沿用实际存活状态与剩余 HP。总览、陷阱示意和随机遭遇场景可能没有固定驻敌，仍有完整的按需 Token 入口。

## 来源与维护

素材来自用户本地《施特拉德的诅咒》目录中的 36 张 PNG、战斗速查和已汉化的 2014 数据卡。源文件只读，地图按原字节上传到既有私有 REFERENCE_DATA bucket。555 条遭遇记录保留原文条件；固定名单中 8 条为随机数量、剩余数量或图外传送终点，见 `shared/strahd/manual-review.json`。

```sh
python3 scripts/build-strahd.py /path/to/施特拉德的诅咒
node scripts/publish-strahd.mjs --remote
npm test
npm run build
npx tsc --noEmit
npx wrangler deploy --domain dnd.xiejiaxue.com --keep-vars
```

`anchors.json` 是经地图视觉核对的区域锚点，使用 650×960 的等比预览坐标（图像在下方 650×930 区域内居中）。构建器转为原图归一化坐标；运行时按当前地图缩放展开。更新地图会改变内容哈希，需要同步更新地图清单及 Worker。

新增模组以 `INSERT OR IGNORE` 加入每位用户的模组库；既有战役不重新初始化。地图由战役素材记录授权，避免跨战役读取；场景遭遇 API 仅对主持人开放。条件遭遇使用命令回执实现重试幂等，保存到对应场景，不改变当前活动场景。

## 重置版 v2

首页「新战役 → 模组 → 施特拉德的诅咒（重置版 v2）」，资料面板标签为「施特拉德重置版」。它来自用户本地《施特拉德的诅咒/重置v2》（地图与原书正文取自同目录的 `原版/05-地图`、`原版/01-章节与场景`）：固定 8 次团的本地重构，不是官方出版物；序章狼群、残灯会、悲痛之心改动等均为本地自编。与原版并存，原版模组不受影响。

- 共 19 张地图（独立的 `map-cosr-*` 资源与 R2 前缀），按场次排列：00 是 v2 自绘的序章战斗图「雾中的狼（废车救援）」（`重置v2/地图示意/第1次_恐狼围攻_纯场景.png`，8×8 格、每格 5 尺，按 100 像素一格预置 Token）；其余 18 张选自原版 36 张地图：总览与旅途、巴洛维亚村、瓦拉吉、克雷茨克、银龙宅邸、鸦阁城堡等。原版 301 份数据卡全部沿用，另加 8 份自编配置（`COSR__*`：达尔万·奥兰斯基、维斯塔尼刀手、列昂尼德、米哈伊、残灯会守卫/哨兵、尤丽娅、悲痛之心）。
- 场景概况取自 v2 的总表与各次场景正文开头（本次要完成、节奏、开场准备）；区域要点取自地点手册与场景正文各段（L0 序章与 L1—L8 每一次的探索地点、小事件、逐轮战斗、随机表和可选线索，按地点放到对应地图；城堡各房间按 K 编号分到城墙、主楼层、伯爵宫廷、诸塔与地下墓穴）。
- 区域要点在 v2 段落之后按原书房间编号列出该图全部房间（如主楼层 K7—K24、银龙宅邸三层 Q32—Q53、死亡之屋 1—38），共 326 个：先写「重置版」——本场景预置或可加入的编组，再写 v2「房间描述」R0—R8 的该室条目（入内所见、细查与通路、人物与剧情）；没有条目的房间列出 v2 文档里提到它的原句，v2 未提及的注明默认不刷敌人或陷阱——再附「原版」章节原文。可在区域要点里按编号搜索。
- 房间描述共 238 条，每条只出现一次：地图上有对应编号的放进该房间，没有编号的（街道、营地马车、村民住宅、城堡 K36/K37/K45 等）作为「R1 · 雾墙」这类区域要点放到对应地图。地点手册里内嵌的同一份描述在区域要点中略去，避免重复。`plan.json` 的 `descriptions` 指定每册默认地图，`by` 按编号前缀改投其他地图。
- 打开地图即见房间描述：主持人切到任一模组地图时，左下角自动展开「房间描述」列表（本图全部房间与本场要点，可搜索）；地图上印着的房间编号外加一圈虚线标记，点圈或点列表即在右上角打开该房间的完整描述。玩家与「玩家视角」看不到。重置版 326 个房间中 277 个已标在图上（同一房间在多层或插图里出现会有多个圈），其余在列表里标「未标」。位置存在 `shared/strahd-remix/area-positions.json`（每张原书地图：房间编号 → 原图归一化坐标，按红色编号圆章检测后人工逐个辨认，城堡黑字编号用文字识别且只收独立成行的编号），构建器把它并入各房间的 `positions`。
- 新战役只放 v2 写明在场的人物与固定编组，共 69 个隐藏 Token。序章图预置两头恐狼（大型，占 2×2 格）和车顶上只剩 2 点生命值的达尔万，困难编组的两只狼增援与前往村庄的可选路障（蝙蝠群、3 只僵尸）在该图「本场景遭遇」里按触发加入；追猎者、残灯会、悲痛之心和施特拉德本人同样按触发加入。

`shared/strahd-remix/plan.json` 选择地图（v2 自带的图用 `mapFile`，可带 `mapScale`、`tokenSize`）、文字段落与编组，`cards.json` 存自编卡；改完 v2 文档后运行 `python3 scripts/build-strahd-remix.py /path/to/施特拉德的诅咒` 刷新数据，上传地图用 `node scripts/publish-strahd.mjs --remix --remote`。`worker/test/strahd-remix.test.ts` 覆盖地图复用、默认编组、主持人专用接口与搜索。
