# 施特拉德的诅咒

首页「新战役 → 模组 → 施特拉德的诅咒 → 创建并进入」。36 张原始地图按章节编号排列，含鸦阁城堡各层、村镇、琥珀神殿与附录死亡之屋。场景首次进入自动适配视窗；在画布尺寸就绪后再绘制，确保含隐藏 Token 的存档刷新正常。沿用现有地图缩放、迷雾、场景切换、Token 拖动、显隐、HP、先攻、战役库、邀请与存档功能。

## 主持人操作

- 新战役自动生成 505 个隐藏 Token，按地图区域锚点展开。位置为区域内可调整的开场布置，城堡等轴图仍需主持人裁定距离。
- 「资料 → 施特拉德 → 本场景遭遇」列出该图所有固定遭遇、在场人物、条件事件、增援与随机备选，含数量、区域、条件、来源页码、数据卡与批量放置。
- 随机数量、存活池与跨层交战不自动实例化；实际触发后输入数量加入。新增单位对玩家隐藏，可用现有框选工具统一显示。
- 「NPC 与怪物库」收录 301 份中文卡（包括场景变体），支持姓名及章节筛选、查看完整能力/动作、放置 Token、加入战役库。
- Token 为与深水城相同用途的姓名圆形标记，采用巴洛维亚配色。原文未给战斗数据的人物保留标记，不编造 HP。
- 跨图重复出现的具名人物不代表多个独立个体；沿用实际存活状态与剩余 HP。总览、陷阱示意和随机遭遇场景可能没有固定驻敌，仍有完整的按需 Token 入口。

## 来源与维护

素材来自用户本地《施特拉德的诅咒》目录中的 36 张 PNG、战斗速查和已汉化的 2014 数据卡。源文件只读，地图按原字节上传到既有私有 REFERENCE_DATA bucket。555 条遭遇记录保留原文条件；固定名单中 8 条为随机数量、剩余数量或图外传送终点，见 `shared/strahd/manual-review.json`。

```sh
python3 scripts/build-strahd.py /path/to/施特拉德的诅咒
node scripts/publish-strahd.mjs --remote
npm test
npm run build
npx tsc --noEmit
npx wrangler deploy --domain dnd.xiejiaxue.com --keep-vars
```

`anchors.json` 是经地图视觉核对的区域锚点，使用 650×960 的等比预览坐标（图像在下方 650×930 区域内居中）。构建器转为原图归一化坐标；运行时按当前地图缩放展开。更新地图会改变内容哈希，需要同步更新地图清单及 Worker。

新增模组以 `INSERT OR IGNORE` 加入每位用户的模组库；既有战役不重新初始化。地图由战役素材记录授权，避免跨战役读取；场景遭遇 API 仅对主持人开放。条件遭遇使用命令回执实现重试幂等，保存到对应场景，不改变当前活动场景。
