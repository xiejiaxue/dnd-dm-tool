# 战争迷雾 + 玩家端 UI 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 网格单元式战争迷雾（FOG_CELL=50 密集格，DM 黄色半透明/玩家不透明遮挡，擦除工具可选笔刷尺寸 + 一键擦除/覆盖）；玩家端保留查询、战役库只显示 DM 解锁场景并提供只读预览。

**Architecture:** `Scene` 加 `fog?: boolean[]`（每格揭示，按 `row*cols+col` 索引）与 `unlocked?: boolean`。迷雾 op（`setFog`/`revealAllFog`/`coverAllFog`）走现有 applyOp（DM 专属）；`updateSceneUnlock` 作为**控制消息**由 GameServer 双路径处理（当前场景改内存+广播，非当前场景加载改文件——参照 `renameScene`）。BoardCanvas 在 map+token 之上渲染角色配色迷雾矩形；擦除工具复用画墙拖拽模式 + 笔刷尺寸选择。玩家战役库 tab 只列 `unlocked` 场景 + 只读预览弹层。

**Tech Stack:** 不变（Node/Express/ws、React/Konva/Tailwind、TS strict、Vitest）。

## Global Constraints

- TypeScript strict；界面文案一律中文；代码标识符/注释用英文。
- `FOG_CELL = 50`（px，共享常量，`shared/types.ts` 导出）。
- 迷雾/解锁 op DM 专属（不在 `isPlayerOp`）。
- 旧场景无 `fog`/`unlocked` → 按全遮挡 / 未解锁（向后兼容）。
- `npm test` 全绿、`npx tsc --noEmit` 干净、`npm run build` 成功。

function ensureFog(scene: Scene): boolean[] {
  if (!scene.fog) {
    const cols = Math.ceil(scene.playArea.w / FOG_CELL);
    const rows = Math.ceil(scene.playArea.h / FOG_CELL);
    scene.fog = new Array(cols * rows).fill(false);
  }
  return scene.fog;
}
```

  // Unlock/lock a scene for players. Current scene updates in memory + saves +
  // broadcasts; other scenes are updated on disk (the switcher reloads).
  private async updateSceneUnlock(sceneId: string, unlocked: boolean): Promise<void> {
    if (sceneId === this.current.id) {
      this.current.unlocked = unlocked;
      this.store.save(this.current);
      this.broadcast({ type: 'state', scene: this.current, campaign: this.currentCampaign });
      return;
    }
    const scene = await this.store.get(sceneId);
    scene.unlocked = unlocked;
    this.store.save(scene);
  }
```

工具函数（在 snap 附近）：
```ts
  // Map a world point to its fog cell index (0..cols*rows-1), or -1 if outside.
  const fogCellAt = useCallback((wx: number, wy: number): number => {
    if (!scene) return -1;
    const cols = Math.ceil(scene.playArea.w / FOG_CELL);
    const rows = Math.ceil(scene.playArea.h / FOG_CELL);
    const cx = Math.floor(wx / FOG_CELL);
    const cy = Math.floor(wy / FOG_CELL);
    if (cx < 0 || cy < 0 || cx >= cols || cy >= rows) return -1;
    return cy * cols + cx;
  }, [scene]);

  // Collect cells under the brush (radius in fog cells) and queue a throttled
  // setFog send.
  const revealAt = useCallback((wx: number, wy: number) => {
    const center = fogCellAt(wx, wy);
    if (center < 0 || !scene) return;
    const cols = Math.ceil(scene.playArea.w / FOG_CELL);
    const centerCol = center % cols;
    const centerRow = Math.floor(center / cols);
    const r = brushSize;
    for (let dr = -r; dr <= r; dr++) {
      for (let dc = -r; dc <= r; dc++) {
        const idx = (centerRow + dr) * cols + (centerCol + dc);
        if (idx >= 0 && idx < (scene.fog?.length ?? 0) && !(scene.fog?.[idx])) {
          eraserBatchRef.current.push(idx);
        }
      }
    }
    if (eraserTimer.current == null) {
      eraserTimer.current = window.setTimeout(() => {
        const cells = [...new Set(eraserBatchRef.current)];
        eraserBatchRef.current = [];
        eraserTimer.current = null;
        if (cells.length) connection.sendOps([{ op: 'setFog', cells, revealed: true }]);
      }, 120);
    }
  }, [fogCellAt, scene, brushSize]);
```
