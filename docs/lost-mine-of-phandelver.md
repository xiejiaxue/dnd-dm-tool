# 凡戴尔的失落矿坑

首页「新战役 → 模组 → 凡戴尔的失落矿坑 → 创建并进入」。7 个场景对应原书全部地图：00 区域总览、01 克拉摩窝点、02 凡达林镇、03 红标帮窝点（崔森德庄园）、04 克拉摩堡、05 雷树镇废墟、06 潮音洞穴。没有专用地图的地点（三猪小径伏击、古枭井、飞龙突岩、阿加莎巢穴）放在区域总览的条件遭遇与区域要点里。

## 主持人操作

- 新战役自动在各房间放置 181 个隐藏 Token（固定遭遇与在场人物），用现有框选工具统一显示。俘虏按原书状态开局：修达 1/27 生命值，甘德伦 0/4（稳定）。
- 战术地图按原书比例校准：一格印刷方格 = 棋盘一格（5 尺 = 100 像素；雷树镇与潮音洞穴原图 1 格 = 10 尺，即两格棋盘）。Token 按体型：微型半格、中小型一格、大型两格。凡达林镇与区域总览没有网格，人物标记较小。
- 「资料 → 凡戴尔」：
  - 本场景遭遇：固定遭遇、在场人物、条件遭遇（返程小队、红标帮恶霸等）与随机遭遇表（三猪小径野外、潮音洞穴游荡怪物），可按数量加入隐藏 Token。
  - 区域要点：每个编号房间的特征、检定 DC、发展、宝藏与 XP，按原书页码整理；含剧透，仅主持人可见。
  - NPC 与怪物库：61 份中文数据卡——附录 B 全部怪物、具名角色（克拉格、玻璃手杖、格罗尔王、黑蜘蛛等）和凡达林镇民（任务与阵营招揽）。也可在「查询」里按名字搜，另一套译名（西达尔、贡德伦、奈兹纳尔、玻璃杖等）同样能搜到。
- 原书没有战斗数据的人物（镇民、里多斯、阿加莎）只给身份与任务说明，不编造 HP。

## 来源与维护

素材来自用户本地《凡戴尔的失落矿坑》目录中的中译 PDF（二校）。地图用 poppler `pdfimages` 按原字节提取，上传到既有私有 REFERENCE_DATA bucket。数据卡（`shared/phandelver/cards.json`）与场景预设（`shared/phandelver/scenes.json`：遭遇、锚点、区域要点）为人工核对的数据；锚点按地图上的房间编号目测标定，使用原图归一化坐标。

```sh
python3 scripts/build-phandelver.py /path/to/凡戴尔的失落矿坑   # 刷新地图元数据、派生字段、index.json 与 output/phandelver
node scripts/publish-phandelver.mjs --remote                    # 先传 7 张地图，最后提交清单
npm test
npm run build
```

构建脚本可重复运行：它从卡片派生每条遭遇的 key、名称、HP、先攻和 Token 体型，生成 `index.json`，并核对锚点范围与自动放置条件。更换地图会改变内容哈希（asset id），需要重新上传清单并发布 Worker。

## 验证

`worker/test/phandelver.test.ts` 覆盖：预设与卡片、地图一致；7 张地图导入、战役素材隔离、全部隐藏 Token 及俘虏起始 HP、体型尺寸；场景预设与区域要点仅主持人可读；条件遭遇命令幂等；中英文与另一套译名搜索、数据卡与 Token 图；缺图时拒绝创建。
