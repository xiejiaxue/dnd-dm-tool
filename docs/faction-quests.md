# 深水城派系任务链

战役桌面「资料 → 深水城 → 派系任务链」提供龙金劫的派系任务链，仅主持人与协作 DM 可见。内容来自本地跑团知识库 `深水城龙金劫-跑团知识库/01-主持人整理/派系任务链`：11 个派系、2 个独立合作者，以及共用规则（接触匹配、派系冲突、日期节奏、登记模板）。

每个派系页依次列出联系人与核心诉求、主持人备注、任务卡和其余章节。默认展开「怎么牵线」（佣兵团为「一页开团速查」）。任务卡可以设为未接、进行中、已完成或失败。顶部搜索会匹配任务编号、标题、奖励、地点和人物，点击结果直接跳到对应任务。有对应 NPC 的派系可以切换到 NPC 档案，并自动按该派系筛选。

任务状态和派系备注存在战役房间状态里（`campaign.questProgress`、`campaign.factionNotes`），通过 `setQuestStatus`、`setFactionNote` 操作修改。它们和遭遇库一样只发给主持人：玩家的投影和补丁中都不包含这两项。备注上限 4000 字，离开输入框时保存。

任务文本只由 Worker 的模组路由 `GET /api/campaigns/:slug/waterdeep-faction-quests` 提供，仅限主持人访问，不打包进前端。

## 更新内容

修改本地笔记后重新生成数据：

```sh
npx tsx scripts/build-faction-quests.ts "/path/to/深水城龙金劫-跑团知识库/01-主持人整理/派系任务链"
```

脚本只读取源目录，输出 `shared/waterdeep/faction-quests.json`。指向其他本地笔记的链接只保留文字，导航行会被去掉。

- 任务表首列为「H1 标题」这类编号的，每一行生成一张任务卡，其余列作为字段。
- 佣兵团按「### 任务一：……」逐节生成任务卡，并从速查表中带上成果、报酬和主要哨站。
- 任务 ID 为 `派系ID:编号`。改编号会使该任务的已有进度失效；改标题或正文不会。
