# 全局搜索

战役桌面按 ⌘K（Windows 为 Ctrl K），或在输入框外按 `/`，也可点顶栏「搜索」，打开全局搜索。一个输入框同时查以下内容，结果按类别分组：

| 类别 | 来源 | 谁能看到 | 打开后 |
| --- | --- | --- | --- |
| 场景 | 本战役场景名 | 主持人 | 切换到该场景 |
| 模组笔记 | 本战役模组地图的场景概况与区域要点 | 主持人 | 在资料面板显示全文，高亮搜索词，可切换到所在场景 |
| 派系任务 | 深水城派系任务链 | 主持人（深水城战役） | 打开「深水城 → 派系任务链」并定位到该任务 |
| 战役日志 | 日志标题与正文 | 主持人看全部，玩家看公开日志 | 打开「日志」中的该条 |
| 规则与数据卡 | 规则书索引和各模组数据卡 | 所有人 | 在资料面板打开数据卡 |

所有词都必须出现才算命中（空格分隔多个词）。标题含有全部搜索词的类别排在前面，所以搜人名会先出现数据卡，搜区域名会先出现区域要点。↑↓ 选择，Enter 打开，Esc 关闭。底部链接把搜索词交给「查询」页签，那里可以按类型筛选，本地没有结果时会查在线资料。

## 实现

- 模组笔记由 `GET /api/campaigns/:slug/notes?q=` 提供，仅主持人可用。Worker 根据战役的 `templateId` 选模组，房间实例把战役中每个场景与该模组的预设地图对应起来（与遭遇预设相同的地图匹配），只搜索本战役确实存在的场景。每次最多返回 30 条。
- 模组在 `AdventureModule.presets` 中声明可搜索的预设场景；新增带区域要点的模组时加上这一项即可。
- 日志、场景列表和任务书在打开搜索时读取一次，在浏览器中过滤；规则书和模组笔记在停止输入 200 毫秒后向服务器查询。
